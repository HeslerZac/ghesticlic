# SATGF — Sitio web

Sitio oficial del **Sistema de Asistencia Tecnológica para Gestos Faciales (SATGF)**, un sistema que permite a personas con discapacidad motriz controlar una computadora mediante gestos faciales y movimientos de la cabeza, sin usar ratón ni teclado.

Proyecto de Graduación — Ingeniería en Sistemas, Universidad Mariano Gálvez de Guatemala, Campus Huehuetenango.
Autor: Hesler Osbaldo Domingo Zacarías.

## Tecnologías

- Next.js 16 · React 19 · TypeScript
- Tailwind CSS 4
- Google MediaPipe (demostración en el navegador)
- pnpm

## Desarrollo local

```bash
pnpm install
pnpm dev
```

Abrir http://localhost:3000

## Producción

```bash
pnpm install --frozen-lockfile
pnpm build
pnpm start
```
